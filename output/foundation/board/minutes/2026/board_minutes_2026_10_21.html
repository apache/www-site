Attachment 2: Report from the VP of Conferences  [Brian Proffitt]

The 2026 Community Over Code Glasgow is done, and on behalf of the planners, I
am pleased to report the event was a very strong success.

In total, 465 people attended both the Lakehouse Day and Community Over Code
events, out of 479 registered, a 97.1% attendance rate, and a 63% increase
from Community Over Code Minneapolis. We will be gathering data in a
post-conference survey soon, but my initial anecdotal findings point to the

quarter and improve the timeliness of follow-up with reporters.

Security reports are handled through security@zeppelin.apache.org in
coordination with security@apache.org, following the ASF security process.
This is what the July report referred to as the private security process.

Apache Zeppelin was founded on 2016-05-18 (10 years ago). There are currently

## Project Activity:
No new release has been published since the July report. The most recent
release is Apache Zeppelin 0.12.1, released on 2026-06-12.

Frontend quality was a major focus. The community expanded unit and end-to-end
tests for notebook editing, collaboration, paragraph behavior, and
visualization rendering. It also corrected tests that could pass without
checking the intended behavior and improved CI reliability. User-facing fixes
covered editor behavior, revision comparison, exports, themes, and
accessibility.

UI modernization continued through incremental React integration within the
Angular UI. Shared Notebook Core work added transport contracts, read state,
and adapters, providing a foundation for the transition while checking
compatibility with existing notebook behavior.

Beyond the frontend, contributors improved notebook persistence and concurrent
operations, interpreter lifecycle and resource management, and WebSocket
connection handling. JDK 17 support was added. Documentation, build tooling,
and dependency maintenance also received attention.

AI assistant work has progressed from discussion and a proof of concept to
server-side notebook chat support. Frontend integration remains in progress.
These changes have not yet been included in a new release.

## Community Health:
OSSCA has brought sustained contribution activity across UI quality, tests,
documentation, and runtime maintenance. As of 2026-10-15, the contribution
dashboard records 276 pull requests, of which 244 have been merged, across
apache/zeppelin and apache/zeppelin-site. Of these, mentees authored 177 pull
requests, with 156 merged. These are cumulative tracker figures since
2026-04-07, rather than counts limited to this quarter.

The dashboard tracks 28 mentees and six mentors; 24 mentees and all six
mentors have authored pull requests in the tracked period. The volume of
contributions is encouraging, and the most visible outcome is stronger
frontend testing and more reliable notebook behavior.

The contribution history also shows work beyond frontend fixes, including
notebook storage, interpreter reliability, and documentation. Our next
community goal is to turn this activity into continued contribution and review
participation after the program, while giving the outstanding security
follow-up focused PMC attention in the coming quarter.
