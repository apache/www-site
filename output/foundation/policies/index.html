ASF Policies

The Apache Software Foundation maintains policies across several areas to ensure consistent governance, legal compliance, and community standards across all Apache projects. This page serves as a central index of all ASF policies.

For a summary of which policies are required (MUST), recommended (SHOULD), or optional (MAY) for Apache projects, see the Board Policy Overview.

Links marked with 🔒 require ASF Member or Committer login.

Code of Conduct & Community Behavior¶

  • Code of Conduct — Applies to all ASF-managed spaces (mailing lists, issue trackers, wikis, chat, etc.)
  • Anti-Harassment Policy — Specific to in-person events and conferences
  • Infrastructure Team Code of Conduct — Infra-specific conduct expectations (references the general CoC)

Legal & Licensing¶

  • Release Policy — Requirements for official Apache software releases
  • Source Header and Copyright Notice Policy — How committers and PMCs should handle source file licensing and copyright notices
  • 3rd Party License Policy — Which third-party licenses are acceptable for inclusion in Apache releases
  • Generative Tooling Guidance — Policy on AI/ML-generated contributions to ASF projects
  • Applying the Apache License — How to correctly apply the Apache License to your project
  • DMCA Designated Agent — Digital Millennium Copyright Act designated agent for the ASF
  • Export Control / Encryption Policy — U.S. export regulations applicable to Apache software distributions
  • Handling Cryptography within an ASF Release — Cryptography export notification requirements
  • Release Download Pages Policy — Requirements for project release download pages
  • Docker Hub Policy — Policy for Apache projects publishing to Docker Hub
  • CLA FAQ — Frequently asked questions about Contributor License Agreements

  • Downstream Distribution Policy — Trademark rules for downstream redistributors

  • Logo Usage Policy — Rules for use of Apache logos

  • Linking Policy — When and how PMCs may link to third-party technical or corporate sites

  • Merchandise Policy — Rules for merchandise using Apache brands
  • Trademark Maintenance Responsibilities — PMC responsibilities for maintaining Apache trademarks
  • Apache Product Name Usage Guide — How to correctly refer to Apache brands in text

  • Incubator Podling Branding Guide — Branding requirements for podlings

  • Public Forum Archive Policy — When and how public mailing list archives may be modified

  • Security Policy — How the ASF Security Team handles vulnerability reports

  • PMC Guide — Required Policies — PMC-specific policy section of the PMC guide

  • 🔒 Conflict of Interest Policy — COI policy development (ASF Members wiki)

  • Board Escalation Guide — How to escalate concerns or problems at the ASF
  • Project Independence — Guidelines for operating independently and for the public good
  • ASF Bylaws — Foundation bylaws covering membership, directors, officers, PMCs
  • Incubator Podling Policies — Policies governing Apache Incubator podlings

Sponsorship & Fundraising¶

  • Targeted Sponsorship Policy — Policy for sponsors supporting specific parts of the Foundation
